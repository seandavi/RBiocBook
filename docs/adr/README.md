# Architecture / project Decision Records (ADRs)

Short, immutable records of significant decisions about this book — its licensing,
structure, tooling, and conventions — in [Michael Nygard's format](https://github.com/joelparkerhenderson/architecture-decision-record).

Each ADR captures the **context**, the **decision**, and its **consequences** at the
time it was made. ADRs are append-only: rather than editing an accepted decision,
add a new ADR that supersedes it and update the older one's status.
