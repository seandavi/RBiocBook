# Image credits and attribution

This folder holds figures used throughout *The RBioc Book*. Most images are
original to the book or simple schematics. The figures listed below were
downloaded from external sources and are reused under the stated licenses.
Each is credited in the figure caption where it appears in the text; this file
is the canonical record of provenance.

> Downloaded locally (rather than hot-linked) on purpose: the render runs in CI
> where outbound network access is unreliable, so every figure must live in the
> repository.
